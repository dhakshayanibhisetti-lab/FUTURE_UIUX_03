# FUTURE_UX_03

## CRM / Client Management Dashboard UI

### Overview
This project is a CRM (Customer Relationship Management) Dashboard UI designed for small agencies and B2B service-based businesses. The dashboard helps users manage clients, leads, projects, tasks, and follow-ups efficiently.

---

## Project Features

### 1. Dashboard Overview
- Business performance statistics
- Revenue analytics
- Lead tracking
- Recent activities section

### 2. Lead Pipeline
- Kanban-style lead management
- Status-based lead tracking
- New Leads
- Contacted
- Proposal Sent
- Closed Won

### 3. Client Profile
- Client information management
- Project progress tracking
- Meeting history
- Contact details

### 4. Tasks & Follow-Ups
- Task management table
- Status indicators
- Upcoming meetings
- Calendar integration

---

## Design Goals

- Clean and modern interface
- Easy navigation
- Improved workflow management
- Better data visibility
- User-friendly experience
